# マイシフト（自分専用シフト管理・自動作成アプリ）

iPad・スマートフォンのブラウザで使える、自分専用のシフト管理アプリです。
毎月の勤務希望を登録して、条件に合ったシフトを自動で作ることを目指しています。

## 公開（GitHub Pages）

公開用のリポジトリ（`my-shift`）の `main` ブランチに変更が入ると、GitHub Actions（`.github/workflows/deploy.yml`）がテストとビルドをしてから自動で公開します。

- 公開先：`https://y-uu329.github.io/my-shift/`
- 最初の1回だけ、公開用リポジトリの **Settings → Pages → Source** を **GitHub Actions** にします。
- メールアドレスが公開されないよう、GitHub の **Settings → Emails** で「Keep my email addresses private」をオンにしておきます。

### iPad・iPhone でアプリとして使う

1. Safari で公開先のURLを開く
2. 共有ボタン（□↑）→ **ホーム画面に追加**
3. ホーム画面のアイコンから起動（オフラインでも開けます。写真の読み取りにはネット接続が必要）

## データの保存場所

データは **使っている端末のブラウザの中（IndexedDB）** に保存されます。
サーバーには送られません。端末やブラウザが変わるとデータは共有されません。
設定画面の「データのバックアップ」で書き出し・読み込みができます（APIキーは含みません）。

## 開発者向け

```bash
npm install      # 最初に1回だけ（必要な部品をダウンロード）
npm run dev      # 開発用サーバーを起動 → 表示されたURLをブラウザで開く
npm test         # 自動テスト
npm run build    # 公開用のファイルを dist/ に作る
```

- 使用技術：TypeScript / React / Vite / IndexedDB（idb-keyval） / Vitest / 祝日データ（@holiday-jp/holiday_jp、2050年まで）
- フォルダ構成
  - `src/domain/` … 条件や日付の計算ロジック（画面とは独立。テストあり）
  - `src/storage/` … 端末内への保存・読み込み
  - `src/components/` … 画面の部品
  - `src/pages/` … 各画面
- APIキーなどの秘密情報は、ソースコードや GitHub に保存しないでください（`.env` は `.gitignore` 済み）。

## 自動作成のしくみ（`src/domain/generator.ts`）

1. **A（絶対条件）**：勤務できない日・出勤できない曜日・確定済みの予定・連勤上限・勤務できる時間帯。これを破る案は作りません。A どうしが矛盾するときは、作成せずに理由を表示します。
2. **B・C（希望条件）**：条件ごとに「何日ずれたか」「何回守れなかったか」を数え、パターンごとの重みを掛けた合計がいちばん小さくなる組み合わせを探します（焼きなまし法）。
3. **3パターン**：希望休重視 / 出勤日数重視 / バランス重視（重みの違い）。
4. **達成度**：条件ごとに実際の日数・回数から計算します（画面に計算式を表示）。総合達成度 =（B の平均 × 2 ＋ C の平均）÷ 3。
5. 同じ条件なら毎回同じ結果になります（乱数の種を固定）。
6. **作り直し**：今のシフトを渡すと、1日変えるごとに小さなペナルティを加えて、変える日がなるべく少ない案を探します。🔒確定の日は確定済みの予定（A）として扱い、変えません。

## 出力（`src/domain/export.ts`・`src/lib/`）

- 画像：月間カレンダーを canvas に描いて PNG に（画面のデザインに左右されない）
- PDF：その画像を A4 に1ページで貼った PDF を自前で作成（追加のライブラリなし・日本語の文字化けなし）
- CSV：Excel で文字化けしないよう BOM 付き UTF-8
- iPad・iPhone では共有メニュー、パソコンではダウンロードで保存

## 写真の読み取り（`src/lib/vision.ts`・`src/domain/importing.ts`）

- Claude API（初期は Claude Opus 5.5、設定で Haiku 5.5 に切り替え可）に画像を送り、決まった形の JSON（日付・出勤/休み/予定・時間・自信の度合い・気になった点）で受け取ります。
- **APIキーはアプリの設定画面で入力し、端末の中（IndexedDB）だけに保存します。ソースコード・GitHub・出力ファイルには入りません。**
- 画像は送る前に長い辺2000pxまで縮小します（料金と通信量を抑えるため）。
- 読み取り結果は一覧で確認・修正してから登録します。読み取れなかった箇所は ⚠️ で表示し、同じ日付の重複や登録済みの内容との重なりは、選ぶまで登録できません。
- Opus を使うときは、安全判定で断られた場合に自動で別モデルへ切り替える設定（server-side fallback）を有効にしています。

## 給料の計算（`src/domain/pay.ts`）

- 給料 = 時給（初期 1,540円）× 実働時間。実働時間 = 開始〜終了 − 休憩。
- 休憩：開始〜終了が 6時間以下はなし、6時間を超えると60分、8時間を超えると90分（設定画面で変更可）。
- 月の合計は、実働の合計分数から最後に1回だけ四捨五入します。
- 「💴 給料」タブ：今月分のまとめ（期間・出勤・実働・休憩・見込み給料・日ごとの内訳）と、締め日（末日または1〜28日）で区切った期間ごとの一覧（前の期間との差、合計・平均）。

## 占いの運気（ゲッターズ飯田さんの月間運気カレンダーなど）

- 「取り込み」→「占いの運気カレンダー」で、占い本の月間カレンダーのページを写真で取り込むと、日ごとの運気（例：開運・乱気）を登録します。記号だけのページは、ページ内の凡例をもとに名前にします。
- 勤務条件の「占いの運気」で、運気ごとに「出勤したい／どちらでも／休みたい」を設定します（翌月にも引き継ぎ）。
- 自動作成では **B（できるだけ守る）** として扱います。ただし、自分で入れた休み希望・勤務希望のほうを優先します。
- カレンダー・画像・CSV にも運気を表示します。
